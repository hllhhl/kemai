课脉 vs LobeHub：Agent 能力对照

对照对象：lobehub/lobehub（约 8.4 万星，聊天式 Agent 平台）。界面图为仓库 public/screenshots/ 里的原图；能力清单来自 README 的 Features 段和 src/features/ 下 183 个真实功能模块。课脉状态按当前已装版本（2026-11-05 22:01 构建）逐项核对。

一、它的界面（4 张原图）

主界面：左侧会话/角色列表 + 搜索，中间聊天气泡，回答下方一排操作按钮与 Tokens 计数，底部输入框与 Send。

多模型选择：按服务商分组列出模型，每项标上下文长度（4K / 16K / 128K）。

多模态：图片输入与视觉理解，右侧还有 Agent 设定面板。

Agent 市场：可安装现成的角色 / 提示词代理，带标签分类。

二、它的能力，逐项对课脉

能力组LobeHub 里对应的模块 / 表现课脉说明
会话与消息Conversation、MessageList、ChatInput、TopicManager、ChatMiniMap；会话列表可搜索、置顶、改名部分聊天气泡、流式、停止、复制、工具轨迹、会话持久化与历史列表都有；缺重试、编辑消息、消息分支、会话搜索/置顶/重命名对应模块：Regenerate / EditingPopover / TopicManager / Favorites
模型ModelSelect、ModelSwitchPanel、ProviderList、OllamaModelDownloader；按服务商分组、标上下文长度部分底部下拉可切换已配置的全部模型，显示当前模型名；没有上下文长度标注、没有本地模型下载引导
工具与 MCPMCP、MCPPluginDetail、Connectors、Integrations、PluginSettings、ToolSetting有18 个工具（8 个课程工具 + 8 个 ltspice MCP + 其他），5 个 MCP 服务器；已在 Agent 循环里真实调用
技能SkillStore、SkillsList、AgentSkillEdit、AgentSkillDetail、CommunitySkillDetail、10000+ 技能库部分21 个技能、渐进加载、质量检查、可在输入框插入；没有技能市场、编辑器、社区库
记忆Memory、MemoryEntities、MemoryRules、MemoryContextStories、SelfLearning、白盒可编辑记忆部分文件式记忆（IDENTITY/SOUL/MEMORY/课程/每日日志），可读可编辑，会话结束自动归档；没有实体抽取、记忆规则、持续学习
权限与安全AgentPermission、GroupPermission、GlobalApprovalNotification、PagePermission、ResourcePermission有sentinel 三态 allow/ask/deny，敏感动作暂停等人确认，全部调用写 audit；循环守卫防重复调用
Agent 角色与设定AgentBuilder、AgentSetting、AgentProfileCard、AgentIdentityModal、AgentArtworkStudio、AgentMarketSubmission没有只有一个固定的「课脉」，不能创建/切换不同角色，也没有 Agent 市场
任务与计划AgentTasks、AgentTaskManager、AgentGoals、Acceptance、TaskDock、RecommendTaskTemplates、DailyBrief没有Agent 内部会自己循环调工具，但界面上看不到计划、待办、验收标准；也没有定时/每日简报
多 Agent 协作AgentGroup、AddAgentMemberModal、ChiefAgent、HeterogeneousAgent、GroupChat、Parallel没有一次只能跑一个 Agent run，没有群组和并行
文档与画布Pages、PageEditor、EditorCanvas、FileTree、FileViewer、DocumentModal、CanvasStorage部分能导出 Word/PPT、资料检索、原文依据跳转；没有可协作编辑的文档/画布
文件与工作区Workspace、WorkspaceSetting、Projects、SandboxDrive、WorkingDirectory、ResourceManager没有资料是「课程」维度，不是项目/工作区；没有沙箱文件系统
多模态AttachmentInput、AudioPlayer、Generation、ArtworkStudio、Visual Recognition没有能上传 PDF/Word/PPT，但 Agent 对话里不能贴图提问，没有语音输入/朗读、图片生成
命令与快捷键CommandMenu、HotkeyHelperPanel、PromptTransform、SettingsSearch没有只有 Enter 发送 / Shift+Enter 换行 / Esc 关菜单；没有命令面板和设置搜索
用量与计费AgentUsage、AgentQuotaCalendar、Tokens 计数、SubscriptionAccounts部分后端记录 token_usage，界面有 TokenUsage 组件，但聊天页没显示本次消耗
分享与导出Share、ShareModal、SharePopover、DataImporter、HeteroSessionImport没有能导出笔记为 Word/PPT，不能导出/分享对话，也不能导入别人的会话
多端与通道Channels、AgentChannel、Messenger、MobileShell、DesktopBridge、IM Gateway没有单机 Windows 桌面应用，没有移动端、IM 接入、远程唤醒
引导与设置Onboarding、DesktopOnboarding、Settings、ProfileEditor、Theme、Recommendations没有没有首次使用引导、外观设置、个性化推荐追问
