# 知页 · 视频伴侣（MV3）

在 B 站页面抓**公开可见字幕**与**画面关键帧**，回传本地运行的知页。

## 为什么需要它

知页后端免登录调 B 站接口时，AI 字幕列表常常为空——不是课程没字幕，而是
AI 字幕只对**带 SESSDATA 登录态**的请求返回。扩展跑在页面上下文，后台
`fetch(..., {credentials:'include'})` 能带上 HttpOnly Cookie，正好补上这条通道。

**本扩展不代登录、不存密码、不碰账号**。它只借用浏览器里用户自己已有的登录态。
如果课程本来就没有字幕（实测很多课 51 讲全空），走第 ⑥ 步的画面 OCR——
那条路**连登录都不需要**。

WBI 签名不在扩展里做，统一调后端 `GET /courses/{id}/finder/sign`——
扩展里就不必再塞一份 MD5 实现。

## 安装

1. 启动知页后端与前端，在知页里建好一门课程。
2. Chrome / Edge 打开 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选本目录。
3. 点工具栏图标，选知页地址（默认 `http://127.0.0.1:8000`）与课程，保存。
4. 打开 B 站视频页，面板里依次点。

## 三种获取方式（用户自己选）

登录与否由**用户**决定，扩展不替任何人做主：

| 方式 | 借用登录态 | 请求字幕接口 | 代价 |
|---|---|---|---|
| **自动**（默认） | 是 | 是 | 先试字幕；读不到自动改成截画面识别 |
| **只用字幕** | 是 | 是 | 最省时间，但课程没字幕时什么也拿不到 |
| **只用画面识别** | **否** | **否** | 不碰登录态、不请求字幕接口，全程本地 OCR，慢一些 |

「只用画面识别」模式下，后台请求用 `credentials: 'omit'`，扩展**不会**携带任何 Cookie。
这就是给不想让工具碰账号的人准备的档位。

## 面板动作

| 动作 | 调用 | 结果 |
|---|---|---|
| 一键处理 | 按当前方式跑完整一讲：字幕→（失败）画面 OCR→要点 | 一条龙 |
| ① 抓取字幕 | B 站四级兜底（签名 → 免签 → 旧版 v2 → pagelist 遍历分 P） | 拿到 `[{from,to,text}]` |
| ② 导入到知页 | `POST /finder/import-transcript` | 资料库多一份「视频字幕」，可检索、可引用 |
| ③ 抽关键帧 | 页面内按画面变化取帧 | 最多 6 张 |
| ④ 画面确认 | `POST /finder/visual-check` | 读画面文字 → 对齐课件页 |
| ⑤ 生成要点 | `POST /finder/digest-part` | 带时间戳的要点，逐条核对 |
| ⑥ 画面转文字导入 | `POST /finder/ocr-frames` | 本地 rapidocr 识别，**不需要登录、不需要模型 Key** |

## 合规边界

- 只提取公开可见字幕与播放器当前画面；
- 不下载视频源文件、不破解限速/会员、不绕过付费字幕；
- 不内置任何 API Key，不向第三方发送数据；
- 数据只写入本机知页。

## 目录

```
manifest.json         MV3 清单（权限最小化）
background.js         proxyFetch（带登录态）/ 转发知页 / 课程与地址记忆
content/bilibili.js   字幕四级兜底 + 按画面变化抽帧
content/common.js     悬浮面板
popup/                选课程与地址
```
